# 🛍️ JastipBandung

Platform Jasa Titip (Jastip) produk kuliner & barang khas Bandung berbasis web, dirancang untuk operasional tim keluarga secara mandiri tanpa kurir pihak ketiga (*Zero-Resi & Internal Direct Delivery*).

---

## 🚀 Fitur Utama
1. **Katalog & Titip Custom:** Pelanggan dapat memesan produk khas Bandung atau mengajukan titip barang tertentu.
2. **Dashboard Operasional 3 Peran:**
   - **Super Admin (Saya):** Manajemen order, inventaris, fee, dan laporan keuangan.
   - **Daftar Belanja Terpadu / Shopper (Bapak):** Rekap item belanjaan per toko di Bandung langsung dari HP.
   - **Packing & Delivery (Adik):** Checklist pengecekan pesanan & monitoring rute antar langsung.
3. **Tracking Pesanan Real-time (Tanpa Resi):** Pelanggan dapat memantau status pesanan (Menunggu ➡️ Dijadwalkan ➡️ Sedang Dibelanjakan ➡️ Dipacking ➡️ Diantar ➡️ Selesai).

---

## 🛠️ Tech Stack
* **Backend:** PHP Native Murni (PDO MySQL)
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla JS), Lucide Icons
* **Database:** MySQL (XAMPP)
* **Server:** Apache 2.4+ (XAMPP)
